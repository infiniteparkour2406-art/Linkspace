# LinkSpace

> Todos os seus links. Em um só lugar.

O **LinkSpace** é uma plataforma de páginas personalizadas no estilo "link na bio", permitindo que cada usuário crie sua própria página com:

- Nome e nome de usuário
- Foto de perfil
- Biografia
- Links personalizados
- Cor personalizada
- Página pública
- Dashboard de edição
- Login por e-mail e senha
- Login com Google
- Firebase Authentication
- Cloud Firestore
- Aplicativo Android através do Median.co
